# Basic HTML Website

A simple multi-page website created as part of my learning journey
with roadmap.sh.

## About the Project

This project demonstrates the fundamental structure of a website
using semantic HTML.

## Pages

- Home: Introduction and overview.
- Projects: A list of projects.
- Articles: Articles about HTML and web development.
- Contact: A contact form with name, email, subject, and message fields.

## Concepts Practised

- Semantic HTML elements
- Website navigation
- Multiple HTML pages
- SEO meta tags
- HTML forms
- Links and lists
- Page headers and footers

## Technologies Used

- HTML5
